# Code of Conduct

AC Server Manager welcomes people with different experience levels, backgrounds and ways of contributing. Everyone taking part in this repository is expected to help keep the community respectful and useful.

## Expected behavior

- Be patient with questions and explain technical problems clearly.
- Discuss the code or the idea rather than attacking the person.
- Respect different opinions, accessibility needs and language abilities.
- Accept constructive feedback and correct mistakes without personal arguments.
- Respect other people's privacy and credit their work.

Harassment, discriminatory remarks, sexual harassment, threats, intimidation, personal insults, deliberate disruption and publishing someone else's private information are not acceptable. Spam and repeated unwanted contact are also unacceptable. Disagreement about a feature or implementation is welcome when it stays respectful.

## Scope

These expectations apply to issues, pull requests, reviews, comments and other community spaces associated with this repository. They also apply when someone explicitly represents the project elsewhere.

## Reporting concerns

Use GitHub's **Report content** / **Report abuse** controls on the relevant comment, issue, pull request or profile. See [GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Where GitHub offers **Report to repository admins**, you can use it to contact the repository's moderators. Reports to GitHub Support are handled by GitHub and are not a private message to the maintainer.

Do not publish personal information or a public account of a sensitive complaint in an issue. Do not use security advisories to report a conduct concern; software vulnerabilities have a separate [security reporting process](SECURITY.md).

## Moderation

The maintainer may ask participants to change their behavior, edit or remove inappropriate content, lock a discussion, or temporarily or permanently restrict participation. The response should reflect the severity and repetition of the behavior. Serious threats, harassment or privacy violations can lead to an immediate restriction.

Moderation should be consistent and respectful. Participants must not retaliate against someone who reports a concern. GitHub's own policies and enforcement apply independently of this project.
